# REVmeet

An Android app for organizing car meets. 

## Current status

- Meeting data model and in-memory store are implemented.
- Meeting list displays current meetings.
- Users can add a meeting through a form.
- Meetings hold details such as:
  - Number of participants
  -  Type of Location
  -  Title
  -  Description
